# TeamFlow sentiment analysis

This folder will contain the chat sentiment dataset, preprocessing and Naive Bayes training code, evaluation notebook, and serialized model artifact.

Planned labels: `positive`, `neutral`, and `negative`.

The backend will load the trained artifact for inference. Keep the dataset source and license with the submitted project documentation. Model artifacts (`.joblib`/`.pkl`) are ignored by Git by default and can be added deliberately once the trained model is ready.
